# projetoSpotify

<p>Nesse projeto, eu me inspirei no Spotify, guardando as musicas em um banco de dados. O usuário poderá entrar e escutar as músicas que já estão listadas no nosso banco de dados, como também listar e favoritar para criar a sua própria playlist, assim como baixar. Esse meu projeto tem o intuito apenas para estudar, sem nenhum intuito de vender.</p>
